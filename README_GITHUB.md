# CoolerBT — GitHub APK Build

این پروژه برای ساخت APK اندروید با GitHub Actions آماده شده است.

## ساخت APK

1. کل محتویات این ZIP را در ریشه مخزن GitHub قرار دهید.
2. به بخش **Actions** بروید.
3. Workflow با نام **Build CoolerBT APK** را انتخاب کنید.
4. روی **Run workflow** بزنید.
5. پس از موفقیت، در بخش **Artifacts** فایل `CoolerBT-APK` را دریافت کنید.

این پروژه از Gradle 8.0.2 و Java 17 در GitHub Actions استفاده می‌کند و به Gradle Wrapper وابسته نیست.
